# iCell Suite dashboard

Static HTML dashboard for **iCell Suite** — iCellR2 · iCellPy · SODA · SODA viewer.

> One suite. One archive. R, Python, and desktop.

**Version:** set in `index.html` via `<meta name="dashboard-version">` / `<meta name="dashboard-date">`
and the top-right `.header-version` badge.

Open locally:

```bash
open index.html
```

Or view on GitHub Pages at `/dashboard/`.

## Tabs

1. **Overview** — shared iCellR2 / iCellPy / SODAviewer design + scale story  
2. **SODA & viewer** — BAM analogy · architecture · R↔Python handoff · SODAviewer  
3. **Pipeline** — core path; optional impute/batch/pseudotime under embedding  
4. **Benchmarks** — three-scale iCellR2 timings + ~1.3M stage table  
5. **Tutorials** — Install · Small · Large · HTO · Batch · **KNetL map** · Imputation · Pseudotime · CITE · VDJ · ST · Visium · ATAC · Multiomics
